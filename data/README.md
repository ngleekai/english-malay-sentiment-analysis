# Dataset location

Download Version 2 of the **Annotated The dUCk Tweets Dataset** from Mendeley Data:

https://data.mendeley.com/datasets/876tc4dkts/2

Place the following files in `data/raw/`:

- `eng_malay_training_dataset.csv`
- `eng_malay_testing_dataset.csv`

The CSV files are intentionally excluded from Git. Keep the official testing file separate until the final evaluation.
